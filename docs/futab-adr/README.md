# FuTab decision records

Every significant decision FuTab makes on its own gets a short record here, numbered in order from `0001` and written from [`0000-template.md`](0000-template.md). A record is never rewritten after it is accepted; a later record supersedes it.

This folder is FuTab's. `docs/adr/` beside it holds OxiGuitar's records, merged in from upstream as they are; they still stand for FuTab unless a record here supersedes one (say which: "supersedes OxiGuitar's ADR 0005"). The two folders are numbered separately, so upstream's next record never clashes with FuTab's.

Design notes (how a feature works) go in [`docs/futab-design/`](../futab-design/).
