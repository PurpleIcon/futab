# FuTab design notes

How FuTab's own features and changes are designed: one Markdown file per feature or area, written before or while it is built, kept up to date as it changes.

This folder is FuTab's. `docs/design/` beside it is OxiGuitar's, merged in from upstream as it is: read it for the design FuTab inherits, but don't edit it (an edit would conflict with every later merge from upstream). When a FuTab change departs from a design in `docs/design/`, say so here and link to it.

Decisions (what was chosen among options, and why) go in [`docs/futab-adr/`](../futab-adr/), not here.
